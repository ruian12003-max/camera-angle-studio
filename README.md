# 镜位台网页原型

这是根据参考视频拆解出的镜位标注与 GPT Image 2 生图工具。标注功能可以直接打开 `index.html` 使用；GPT Image 2 生图需要运行本地服务。

## 已实现

- 上传或拖入场景图片，数据仅在本地浏览器中处理
- 在画面上直接拖拽绘制带透视感的红色镜头箭头，圆环尾部代表机位，箭头代表拍摄方向
- 箭头越长焦段越长；也可用焦段滑杆或 24/35/50/85mm 预设精调，箭头长度会反向联动
- 箭头越粗代表光圈越大、景深越浅；光圈使用下方滑杆或预设按钮调整，页面滚轮保持正常上下滚动
- 鼠标左键拖拽表示朝画面深处推进，右键拖拽表示朝画面前方反打；触屏可使用纵深按钮
- “三维拍摄方向”和红色高亮的 Z 轴读数会明确区分深入/反打；相同 XY 箭头下俯仰角与景别保持一致，避免伪造镜头参数
- 自动判断机位区域、左右方向、俯拍/仰拍角度、纵深方向和箭头角度
- 人物观察方位独立控制：正面、前侧 45°、侧面 90°、后侧 135°、背面 180°
- 景别与焦段解耦，可独立指定大全景、全景、中景、近景、脸部特写或大特写
- 可选择人物、脸部/眼睛、上半身、全身、物体或环境为对焦对象，并在画面上点选青色对焦点
- 图片可拖入页面任意位置直接替换，按回车可触发生图（在提示词编辑框内除外）
- 自动生成可编辑的中文图像/视频模型提示词
- 导出带标注 PNG、镜位参数 JSON
- 桌面端和移动端自适应布局
- 直接调用 `gpt-image-2`，使用无标注原图生成新机位
- 支持 1K / 2K / 4K、草图 / 标准 / 高清、自动比例及 1:1 / 16:9 / 9:16 / 4:3 / 3:2
- 一键检测第三方 API 的 DNS、HTTPS 端口、`/v1/models` 接口和 API Key；通过时“检测”为绿色，失败为红色并显示具体原因
- 网页内展示、下载生成结果，或将结果继续设为参考图

## 启动 GPT Image 2

1. 安装 Node.js 20 或更高版本。
2. 双击 `start.cmd`，浏览器会打开 `http://127.0.0.1:43127`。
3. 在网页中填写第三方 `API URL` 与 `API Key`；两者只保存在当前页面内存，刷新即清除。URL 可填 `https://服务商域名/v1`，程序会自动补全 `/images/edits`；也可填写完整接口地址。点击“检测”会先检查 DNS 和端口，再用不生图的 `GET /v1/models` 验证接口与 Key。
4. 更推荐复制 `.env.example` 为 `.env`，填入 `OPENAI_API_URL` 和 `OPENAI_API_KEY` 后重新启动。这样凭据只保存在本机服务端，不进入网页。

## 部署到公网

项目已包含 `Dockerfile` 和 `render.yaml`，可部署到支持 Docker 的云平台。以 Render 为例：将 `outputs/camera-angle-studio` 目录上传到 GitHub，在 Render 中选择 New Web Service → Existing repository，Root Directory 填 `outputs/camera-angle-studio`，运行方式选择 Docker，然后部署。部署完成后，把服务生成的 HTTPS 地址发给别人即可。

公网部署时不要把 API Key 写进 GitHub 或 `Dockerfile`。建议让每位使用者在网页内填写自己的 API URL 和 API Key；网页不会保存或展示 Key。若使用服务端环境变量，请在云平台后台配置 `OPENAI_API_URL` 和 `OPENAI_API_KEY`，不要提交 `.env` 文件。

工具调用 OpenAI 兼容的图片编辑接口，模型固定为 `gpt-image-2`。第三方接口可以返回 `data[0].b64_json` 或 `data[0].url`。生成结果会显示在页面下方，最多保留最近 6 张；刷新页面后清除。

## 产品版建议

前端可迁移到 React / Next.js，并增加项目保存、镜头列表、多人协作、用户账号、用量统计和服务端任务队列。

目前的二维箭头是镜头意图标注，不是严格的三维相机求解。若要输出真实的相机位姿，需要加入场景深度估计、消失点/地平线标定，或直接使用 Three.js 三维预演视窗。
